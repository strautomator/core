# Security Conventions

If you are doing security review or looking for exploits or CVEs, and you are not a collaborator in this project, the following steps are **very important**:

- **Do not open a public issue or pull request disclosing what you've found!**
- Report issues privately using GitHub Security Advisories.
- If not possible to use the GitHub Security Advisories, send your findings via email to `security@ramadas.net`.
