# Frontend Conventions

- **Mobile-first!** When doing work on the a frontend, consider that it will be used mostly using mobile devices.
- The mobile and desktop should have feature-parity for all the important features of the app / service.
- Additional minor features might be added to the desktop version of frontend (for example, additional filters when searching data, or different view styles, etc.).

## SCSS and CSS

- Prefer SCSS, and fallback to CSS only if the current project is using CSS exclusively.
- Styles must be modular and lean. Reuse existing styles whenever possible.
